# TestPilot Windows运行包

## 启动

完整解压到可写目录，双击“启动测试工作台.cmd”。包内已有Node和运行依赖，不需要Codex，也无需首次npm下载。不要在ZIP预览中直接运行。

网页默认地址：http://127.0.0.1:4325/dify/?page=dify-regression。

第一次启动自动建立部门申样项目，包含131条用例、已有脚本、前置和4条核心链路；日常范围39条。报告为空，全部未执行，不带原开发者账号、截图和记录。57条尚无步骤的用例如实保留。

## 连接与运行

本地工作台启动不需要额外服务部署。实际业务测试仍需网络、Microsoft Edge、本人测试账号及相应数据库/审批/库存/下游条件。按网页配置后选择范围执行，不能将“有脚本”视为“业务已通过”。

## 数据与升级

本人数据默认保存在%LOCALAPPDATA%/TestPilot/workspaces/dify。可以用TESTPILOT_DATA_HOME设置其他绝对目录；运行记录、截图、账号配置和浏览器会话都留在这里，不随程序包分发。

升级前双击“停止测试工作台.cmd”，将新程序解压到新目录后启动，使用同一数据目录。已有项目不会被初始化覆盖。发现旧版程序目录内数据时，先按docs/tooling/local-data.md受控迁移，不要创建空白替代。

## 常见问题

- 端口占用：确认是否已有实例；启动器只复用相同程序路径的实例，不关闭未知进程。
- 页面没有资源：查看/api/system-module-regression/resources/initialization，检查资源文件和摘要。
- 无法连接业务系统：检查网络、本人登录及所选用例的环境条件。
- 原程序仍在运行：先用原程序停止入口关闭，再启动新版本。

安装与维护说明在docs/tooling，RELEASE.json记录程序来源、资源数量及运行要求，MANIFEST.sha256用于核对包体。将整个文件夹交给Agent时，先让它阅读README.md和AGENTS.md；MCP接入包在“用例与脚本→AI接入说明”下载。整份新版用例使用“更新用例”，离线报告包在“运行报告”下载。
