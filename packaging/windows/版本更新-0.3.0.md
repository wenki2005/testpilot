# TestPilot 0.3.0

发布日期：2026-10-28。

## 2026-11-03 A01 导航与自动选页交付

- 新增网站地图：探索当前账号可见的菜单、列表、详情，保存实际入口顺序，并支持路径复验。
- 修复探索页面目标失效、异步加载改变入口索引，以及页面关闭时重复处理网络请求导致服务退出的问题。
- 用例准备支持根据模块、页面内容和记录身份自动选页，引用原始证据；申请与订单页面不互相替代，缺少真实详情时保留未解决状态。
- 工作台区分历史探索完成和当前服务启动后的路径复验；重启后不沿用旧的可用状态。
- 已有部门申样书 PC 登录会话中完成全新7页/28导航探索、连续三轮7/7路径复验，以及最终代码重启后的7/7复验；三个选页正例和一个缺订单详情负例通过。85项定向工程检查通过。
- 同时包含此前的 Agent 数据库只读证据接入和字段复核修复。数据库事实、导航成功和局部检查分别记录，未执行项目不计为通过。
- 分发包不内置开发机项目、模型密钥、数据库密码、通知地址或浏览器登录态。解压后的安装、启动和接口验证另见随包发布验证记录；不代表在新机器已完成真实业务验收。

## 2026-11-02 尊重逐次运行确认策略（R13q）

- 项目启用“每次运行前确认”时，新建的自主回归计划不会自动启动；工作台要求用户确认本轮范围后提交。
- 执行服务和HTTP入口再次强制确认，空请求不能绕过项目策略；只接受显式确认字段，范围仍完全来自已保存的计划。
- 自动运行策略未启用逐次确认的项目保持原有行为。新增服务端、HTTP、工作台和合成浏览器覆盖。
- 真实业务站点、真实模型及12条业务候选仍未验收；后者按用户要求暂缓正式化并继续阻断。

## 2026-11-02 自主回归安全就绪后自动执行（R13p）

- 创建新计划后，只有计划当前有效、结论为已选范围、服务端状态为 ready 且确有执行用例时，工作台才在核实该计划尚无执行记录后自动提交回归，不再要求用户逐条挑选或再次点击启动。
- 过期/阻断/需要澄清/未发现相关用例的计划不自动提交；服务端继续验证项目审核状态、用例步骤、前置、只读副作用风险、证据引用与冻结范围。历史计划保留人工启动入口；不确定提交状态不会自动重试。
- 新增计划门槛单测和本地合成页面浏览器联调。全量源码门禁：184 个 Node 测试文件、608 项 Node 测试、15 项 Playwright 测试、304 个架构模块，均通过；web 构建通过。
- 联调用本地模拟计划和合成页面，不代表真实业务网站、真实模型或业务选例质量已验收。

## 2026-11-02 页面探索候选字段白名单（R13o）

- 探索候选由服务端白名单重建，只接收候选 ID、观测事实和服务端绑定的页面证据/只读断言；模型提供的模块路径、依赖、标签、数据schema、基线、执行提示和生成轨迹不会被继承。
- 保留P3、低置信度、草稿、未选择、业务预期待确认等约束。对抗性候选元数据测试与真实生产规划链路集成测试均覆盖该边界。
- 完整源码门禁通过：184 个 Node 测试文件、607 项测试、14 项 Playwright 测试、304 个架构模块；web 构建通过。
- 本地模拟模型与合成站点结果不代表真实业务验收。

## 2026-11-02 页面探索候选边界修复（R13n）

- 页面观察候选现在清除模型生成的清理指令，避免把未证实的业务副作用带入只读探索资产；预期、优先级、类别、置信度、前置和测试数据均由服务器按实际页面证据重新限定。
- 本机模拟 Chat Completions 集成使用含错误审批推断和撤销指令的模型候选，确认最终只保存页面中观察到的文本、只读断言和待确认业务预期。
- 全量源码门禁通过：184 个 Node 测试文件、607 项测试、14 项 Playwright 测试、304 个架构模块；web 构建通过。
- 真实业务网站、真实模型质量、真实角色及 156 条业务用例仍未验收。

## 2026-11-02 本机页面探索与候选生成闭环验证（R13m）

- 跨页合成集成调用生产 Chat Completions 客户端、页面探索决策适配器和用例规划器；本机模拟模型依次返回“跟随可见链接”“停止”和基于需求/两页证据的探索候选。
- 服务端将候选严格降为 P3、低置信度的当前页面观察，并只生成有页面证据支撑的只读可见性断言；证据和修订记录可追溯，候选仍须人工审核后才具备运行资格。
- 页面探索与适配器定向测试 5 项通过；R13l 全量源码门禁为 184 个 Node 测试文件、607 项测试和 14 项 Playwright 通过，架构 304 个模块，web 构建通过。R13m 相对 R13l 未改生产源码。
- 所有模型与目标页面均为本地合成服务，不代表真实模型质量、真实业务网站或业务回归已验收。

## 2026-11-02 本地审核链路更新（R13j）

- 页面探索候选会保留跨页决策轨迹和各页摘要；用例、步骤和证据修订可在项目历史中核对。候选生成后仍为草稿且未选择，须由使用者检查、标记可运行、选择并审核后才会进入运行范围。
- 修复审核保存时目标网址未改变却清除页面探索记录的问题；修复人工将候选改为可运行或选择后丢失可信页面证据的问题。
- 新增本地合成页面的端到端检查，覆盖跨页候选、项目更新/选择/审核、存储重载、修订历史、审核界面及运行前审核门槛。
- 完整本地源码门禁：607 项 Node 测试、14 项 Playwright 测试通过；分发包另行通过干净安装、自测、服务健康和预置缺陷复现。
- 这些检查使用 localhost 和合成证据，不代表真实业务站点、真实模型质量、真实角色或156条业务用例已验收。
