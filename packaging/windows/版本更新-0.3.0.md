# TestPilot 0.3.0

发布日期：2026-10-28。

- 源码 Agent 接通真实 Node 测试执行、失败反馈、源码搜索和继续调查。
- 增加候选修订留档、修订后复测、证据分页回读、执行次数及模型用量记录。
- 修复流式响应事件计数导致的提前中断，以及取消时遗留测试子进程的问题。
- 接入官方 Playwright Test 执行与证据解析；完善装饰性 SVG、canvas 和 iframe 的文本判定。
- 修复分发包缺少可选源码项目的问题，加入匿名数量样例。
- 源码搜索改为显式项目依赖，消除开发机 PATH 的隐式依赖。
- 分发脚本从当前源码重新构建并校验清单，避免重新压缩旧构建。

0.3.0 是独立应用，不调用 Codex SDK/CLI，也不要求安装 Codex。开源工程参考不等于整体能力已经与 Codex 相同。

核心改动此前通过 202 项 Node 检查和 8 项浏览器检查。受控多文件及真实 Edge 样例的同一套 45 项测试，在预置缺陷版本中 28 项失败，在独立修复对照中全部通过；它们不代表某个真实业务项目的全量验收结果。

本包的启动、自检与分发检查另行执行，验证结果见发布时附带的校验记录。
