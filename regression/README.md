## 一条用例怎么落地

1. 从原 XMind 记录编号或完整分支路径，补齐原文省略的步骤和数据。
2. 人工跑一次，确认测试环境、账号和预期可用；不清楚就标待确认。
3. 沿用现有 TestPilot 执行机制编写或导入脚本，在模块目录说明运行方式。
4. 检查业务断言和失败证据，交给另一人在相同条件下重跑。
5. 通过任务分支提交和合并，不在 main 上开展日常开发。

当前模块目录只包含规划和空白任务表，不包含假定可执行的业务套件。前端接口返回结构、测试账号与正式 XMind 基线尚需核实。
