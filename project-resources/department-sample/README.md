# 部门申样项目资源

包含131条用例、对应脚本、前置、5模块及4条核心链路，每条用例和脚本按稳定ID保存。

- cases：原文、预期、人工步骤、前置及来源。
- scripts：已有有效步骤；无步骤的定义仍保留。
- modules.json：模块目录及已核对的日常执行范围。
- chains：程序支持的核心链路及步骤引用。
- config、fixtures：不含凭据的配置与测试输入模板。

不含运行记录、通过状态、截图、账号或登录态。新数据区首次启动自动初始化；已有项目不自动覆盖。编辑文件后使用资源预览/应用接口或resources:sync同步，直接修改不会静默更新网页。完整运行包仍须按交付计划装配。
