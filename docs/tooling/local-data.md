# 本机数据与升级

## 默认位置

Windows默认放在%LOCALAPPDATA%/TestPilot/workspaces/dify，程序目录替换时不覆盖这里。

此目录保存本人项目版本、运行记录、报告备注、截图、数据库连接配置和浏览器登录会话。源码和内置资源在程序目录，真实数据不加入Git。

| 配置 | 用途 |
| --- | --- |
| TESTPILOT_DATA_HOME | TestPilot本机数据总目录，要求绝对路径 |
| TESTPILOT_RUNTIME_DIR | 工作区父目录，默认数据总目录/workspaces |
| TESTPILOT_DATA_DIR | 单个服务的数据目录，供专用启动或隔离验证 |

正式启动使用npm run workbench:start或根启动文件。兼容入口在加载适配器前设置数据环境，避免部分服务误写回程序目录。GET /api/config中的storage报告实际位置。

## 旧数据迁移

已有程序目录内的数据不会被当作“新安装”忽略。启动器发现旧数据而外部数据未建立时会停止并提示迁移，防止出现空白替代。

先关闭对应工作区及它管理的浏览器，再预览：

```powershell
npm run data:relocate -- --workspace dify --source <旧数据目录>
```

核对目标位置后应用：

```powershell
npm run data:relocate -- --workspace dify --source <旧数据目录> --apply
```

工具保留源目录作为回退副本，目标必须不存在。实际复制记录、截图、私有配置和浏览器档案；SQLite使用一致性备份并检查完整性，内部文件引用同步到新位置。复制前后核对源文件摘要，写入暂存目录后才切换目标目录；运行中的源进程或浏览器会被拒绝。

迁移收据只留在本机目标目录。未完成的暂存目录不作为可用数据；修复原因后再迁移。不要把旧工作区直接拖进源码仓库或上传其数据库。

## 升级规则

替换程序目录后使用相同的数据总目录，保留本人运行记录和设置。已有项目不会被初始化覆盖，资源更新通过预览产生新版本。默认不删除旧迁移源，统一验收后再决定回退副本的清理。
