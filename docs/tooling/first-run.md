# 首次启动

## 自动初始化

源码版安装依赖并构建后运行npm run workbench:start。服务从project-resources/department-sample加载项目定义，在自己的数据区创建项目和模块版本。

新使用者应看到：

- 部门申样项目、5模块、131条用例、4条核心链路。
- 已有74条步骤和57条待补步骤的定义，39条日常用例选择。
- 全部未执行，运行报告为0；没有原开发者账号、浏览器登录态、申请号或执行截图。

真实测试前仍需连接本人账号及必要的测试环境、数据库和下游服务。初始化不会打开被测页面，不提交业务操作，不调用模型，也不开启通知。

## 已有项目

按稳定项目ID判断是否已初始化。重复启动不会重复建立项目，不覆盖本机修改、历史版本、报告或账号配置。资源更新需从“用例与脚本 → 资源”预览和应用。

## 环境参数

| 参数 | 用途 |
| --- | --- |
| TESTPILOT_RESOURCE_DIR | 自定义资源目录，默认随程序的project-resources/department-sample |
| TESTPILOT_RESOURCE_TARGET_URL | 目标环境地址，默认已约定的部门申样测试入口 |
| TESTPILOT_RESOURCE_ENVIRONMENT | 环境名称，默认“测试” |
| TESTPILOT_AUTO_INITIALIZE=0 | 禁用自动初始化，用于专用工具环境 |

GET /api/system-module-regression/resources/initialization返回初始化状态。资源缺失、摘要不符或格式不兼容会给出错误；空数据区不会伪造一个已加载成功的项目。
