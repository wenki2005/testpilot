# 项目资源同步

## 网页操作

“用例与脚本”右上角的“资源”支持导出和导入JSON资源包。

1. 导出当前项目。
2. 修改用例、对应脚本或前置编号；保持项目、模块、用例ID稳定。
3. 导入后查看新增、修改、移除和未变清单。
4. 应用后创建新的模块版本，网页和执行测试读取此版本；保存不会执行测试。

预览以后若有人修改了模块，应用返回409，必须重新预览。未变模块复用版本；被移除模块归档，旧用例版本和报告保留。非法步骤、循环前置、跨项目依赖、状态和结果字段会被拒绝。核心链路执行模板仍由程序维护，不接受通过资源包任意改写。

## 逐条文件同步

先构建当前代码并运行服务，再预览目录：

```powershell
npm run resources:sync -- --dir project-resources/department-sample --allow-edits
```

确认输出的差异后，使用该次预览的revision：

```powershell
npm run resources:sync -- --dir project-resources/department-sample --allow-edits --apply --base-revision <revision>
```

--base-url可指定本机服务，默认4323。--allow-edits用于有意编辑后摘要与旧清单不一致的情况；默认拒绝摘要不符。工具不读取任意外部文件，不运行脚本、不调用模型或被测业务。

文件是受控导入源，直接改文件不会绕过预览覆盖网页。第一次安装自动初始化在M02实现。
