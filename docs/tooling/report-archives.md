# 报告归档与移交

入口：**运行报告 → 报告格式选“离线报告包” → 下载**。可下载单份或选择多份打包，最多10份、总量128MB。运行中的批次不归档。

解压报告ZIP后打开index.html，无需启动TestPilot即可查看用例、预期、实际结果、版本和已有截图。整个文件夹可以移交给团队，或放到团队批准的静态网页空间；工具不会自动对外上传。

## 包内内容

| 文件 | 内容 |
| --- | --- |
| index.html | 可离线查看的报告 |
| report.json | 对应运行的定义、版本、结果和元信息快照 |
| evidence/ | 本批次引用的已有PNG截图 |
| manifest.json | 文件SHA256、项目、批次和缺失证据清单 |
| README.txt | 查看方法 |

不包含数据库、账号配置或登录态。截图不可读或PNG内容无效时明确列出缺失，不挪用其他图片；原运行结果保持原样。报告中的业务内容和截图仍应按团队规则管理。

## 与其他入口的关系

执行测试负责启动和查看当前运行。运行报告统一管理历史运行的名称、备注、重要标记和下载。Excel、XMind与离线包使用同一批次来源，属于不同导出格式。

本机原始记录、截图和报告注记保留在外部工作区；升级程序不覆盖。源码和资源种子不带这些内容。离线包是查看快照，不会导入成当前“最新通过”结果，也不会触发复测。

## 验证

合成失败报告验证结果及版本保留、PNG摘要、全文件校验清单、HTML转义、离线路径和缺失图片提示；运行中批次及外部证据路径拒绝。未发布报告到任何外部服务。
